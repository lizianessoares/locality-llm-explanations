## Supplementary Material

The materials provided in this repository support transparency, reproducibility, and further research on LLM-mediated locality-based explanations.

The complete audience-aware prompt templates described in the paper are provided below. These templates correspond to the final prompts obtained through the iterative human-centered prompt design process described in Section 4 of the paper.

📄 [Technical Audience Prompt](prompts/technical-audience-prompt.md): contains the complete prompt template designed for users with technical and machine learning expertise, including the instructions and constraints used to communicate locality structure, semantic variability, and uncertainty.

📄 [General Audience Prompt](prompts/general-audience-prompt.md): contains the complete prompt template designed for non-technical users, prioritizing plain language and readability while preserving the relevant semantic characteristics and uncertainty of the locality.
